EMAIL FILER (TEST) - prototype
================================
Purpose: test whether a "file before sending" step works in Outlook.
It does NOT save anything to SharePoint and contains no client data.

Files
  manifest.xml    tells Outlook about the add-in (edit the web address first)
  commands.html   background page that runs when you press Send
  launchevent.js  the Send check
  taskpane.html   the filing panel
  taskpane.js     the filing panel logic
  assets/         icons

Before use: in manifest.xml replace every YOURNAME with your GitHub user name.
Follow the step-by-step guide given in the chat.
